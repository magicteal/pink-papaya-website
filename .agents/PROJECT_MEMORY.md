### 🏛️ Architecture & System Overview
- **Core Framework**: Next.js 15 (App Router, Turbopack, React 19) paired with Tailwind CSS v4 (PostCSS plugin, no `tailwind.config.js`, variables declared directly in CSS).
- **Database & Data Store**: MongoDB via Mongoose (v9) with connection pooling in `src/lib/mongodb.ts`. Primary models: `Stay`, `User` (RBAC: `admin`, `cms_editor`), `MediaLibrary`, CMS Content stores (`locations`, `collections`, `blog`, `interior`).
- **Auth & Security**: Custom HMAC-signed cookie authentication in `src/lib/auth.ts` (`pp_auth_token`), protecting `/admin` and `/cms` routes via `src/middleware.ts`.
- **Public vs Staging Domain Routing**: `src/middleware.ts` redirects public domain `pinkpapayastays.com` to `/coming-soon`, while full site access is enabled on VPS IP (`187.127.187.184`) and `localhost`.
- **Media & Assets**: Uploads handled via Sharp with server-side WebP pre-optimization (`src/lib/media-storage.ts`). Official SVGs in `/public/logo-files/` (`logo-black.svg` on light themes, `logo-white.svg` on dark themes).
- **Animations & Carousel**: GSAP v3 for marquee/testimonials, Framer Motion (`motion` v12) for page transitions, and Embla Carousel for stay card image carousels.

### 📐 UI/UX Layout Standards & User Preferences
- **Site-Wide Width Standard**: All major section containers use `w-[90%] max-w-[1552px] mx-auto` to prevent ragged edges across displays up to 27" (2560px).
- **Stay Card Proportions**: `StayCard.tsx` strictly uses `aspect-[16/10]` for stay images with 4-column responsive grid on xl+ screens and 3-column inner spec pills (`bed`, `guests`, `area`).
- **Whitespace**: Tight vertical padding between home sections; avoid large empty gaps.
- **Typography & Brand Palette**: Playfair Display (editorial serif) and Bricolage Grotesque (body sans); primary accents in warm parchment (`#FDFAF6`), slate green (`#16323C`), and papaya coral tones.
- **Flexible Pricing**: Supports "Price on Request" handled gracefully via `formatPriceString` in `src/utils/formatCurrency.ts`.

### ⚠️ Known Gotchas & Constraints
- **Dev Server Port**: `npm run dev` executes `scripts/dev.js` which automatically resolves and binds the first free port (starting at 3000).
- **Cookie Security Setting**: `secure: false` is set in `src/lib/auth.ts` for local/IP testing; must switch to `secure: true` before HTTPS domain launch.
- **VPS Deployments**: Deployment uses `scripts/vps-deploy.js` (SSH pull, install, build, PM2 restart). Automated check is available via `/pinkpapayalive` skill.
